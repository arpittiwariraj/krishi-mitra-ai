
# KRISHI MITRA AI — OPENCODE PROJECT RULES

You are the lead software engineer responsible for building Krishi Mitra AI from scratch.

## Mandatory project requirements

1. Read PROJECT_SPEC.md before starting development.
2. Follow the exact technology stack specified in PROJECT_SPEC.md.
3. Build actual working software, not just UI mockups.
4. Use React.js, JavaScript and Tailwind CSS.
5. Use Python and FastAPI for the backend.
6. Use PostgreSQL for the database.
7. Use OpenAI Multimodal API for crop image analysis.
8. Integrate OpenWeather, AGMARKNET/data.gov.in and verified government scheme sources.
9. Keep frontend and backend in separate directories.
10. Never expose API keys in frontend code.
11. Never fabricate disease confidence percentages, market prices or weather data.
12. Handle errors and missing API credentials properly.
13. Keep code modular, reusable and documented.
14. Do not create unnecessary technologies or replace the requested stack.

## Development workflow

- Inspect the existing project before changing files.
- Maintain a development checklist.
- Implement one phase at a time.
- Test every major feature before moving forward.
- Run the frontend and backend after implementation.
- Fix errors rather than hiding them.
- Do not delete existing work without checking its purpose.
- Never overwrite user files without inspecting them.

## Development priorities

1. Project initialization.

3. Multimodal crop disease detection.
4. Weather advisory.
5. Market price analysis.
6. Government scheme finder.

## Coding standards

- Use clear names.
- Write reusable components.
- Use proper API validation.
- Use environment variables for secrets.
- Keep API calls in service modules.
- Use structured JSON responses.
- Add meaningful error messages.
- Maintain responsive design.
- Keep Hindi and English support.

## Important instructions

Do not stop after planning.

Do not merely provide code snippets.

Create and modify actual project files, install required dependencies, run commands, test the application and continue until the requested phase works.

If API credentials are unavailable, implement the integration with proper configuration and report exactly which credentials are required.

Read PROJECT_SPEC.md whenever you need the full feature requirements.
